# CET-6 Speaking Coach · 六级口语陪练

固定练习个人陈述和双人讨论。用步骤与对话轮数控制进度，不计时；每次用户说 **That's all.** 后，AI才继续。明确的暂停、继续、结束训练和请求提示命令可以立即执行。

## ChatGPT 手机使用

1. 打开 [CHATGPT_PROMPT.md](./CHATGPT_PROMPT.md)，复制全部内容，粘贴到 ChatGPT 新聊天发送。也可以下载文件后上传，并明确要求按其中的训练规则执行；以实际读取成功为准。
2. 有昨天的“明日复盘卡”时，把它和训练指令一起发送；没有记录则直接开始今日陈述。
3. 先发送文字指令，再进入你使用的语音对话方式。每一次回答和重说均以 **That's all.** 结束。不要只在整场训练最后说。
4. 结束后保存“明日复盘卡”。下次新聊天重新发送训练指令和复盘卡。

最简单的启动语：`请按以上规则开始今天的六级口语训练。没有昨日记录，直接进入今日个人陈述。`

GitHub 用于分发训练文件；这里不把 GitHub 链接视作已经安装或加载了 skill。手机入口是可直接粘贴的完整指令。指令能规定训练行为，但无法保证控制语音客户端的自动分段、抢话，也不能保证模型零偏差。文字交互中未出现结束标记时，预期行为为不产生训练回复。实际手机语音表现尚需试用验证。

## 固定流程

昨日陈述回忆 → 纠错 → 重说 → 昨日讨论结论回忆 → 纠错 → 重说 → 今日陈述 → 纠错 → 重说 → 今日讨论 → 今日总结与明日复盘卡。

今日讨论为10组交流：每组AI一次、你一次，共20次发言。1–3轮交换看法并确定范围；4–8轮围绕你的真实例子展开；9–10轮总结和补充。等你的第10次回答结束才总结。讨论不逐句纠错，结束后统一处理。

本流程是练习安排，不是完整考试模拟。六级口试还包含自我介绍与问答；考试形式依据：[中国教育考试网 CET口试](https://cet.neea.edu.cn/html1/folder/16113/1587-1.htm)。

## 支持 skills 的客户端

将这个文件夹安装到客户端的 skills 目录，入口是 [SKILL.md](./SKILL.md)。调用示例：`使用 $cet6-speaking-coach 开始今天的训练。`

`SKILL.md` 为训练规则的唯一维护源；手机提示词由其正文生成，两者应保持同步。仓库不保存个人练习记录。
